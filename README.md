# סטודיו עבודה — דמו אפיון

**תיאור לריפוזיטורי:** דמו אפיון לתיק עבודות: אותם מסכים ודמואים חיים, נתונים בדויים, בלי מייל, תשלום או מפתחות. כל הזכויות שמורות לאופיסנס ולביזנס-רום.

הדגמה לתיק עבודות של טופס אפיון מערכת, עם אותם מסכים ואותם דמואים חיים.

כל הזכויות שמורות לאופיסנס (Ofisense) ולביזנס-רום (Business Room). השורה הזו, יחד עם הלוגו של שתיהן, מופיעה גם בראש כל מסך.

הפרסום הזה מיועד להצגת תוצרי העבודה בתיק עבודות, ובלבד ש:

- מצוין באופן ברור שהזכויות שמורות לאופיסנס ולביזנס-רום.
- אין בפרסום פרטים מזהים של לקוחות, לרבות שמות ונתונים אישיים.
- אין בפרסום מידע סודי או רגיש.

השמות, הארגונים ומספרי הטלפון במסכים בדויים. אין כאן מפתחות, סיסמאות, חיבור תשלום או שליחת מייל. טיוטה נשמרת רק בדפדפן של מי שצופה.

אין בפרסום הזה רישיון לשימוש מסחרי בקוד או במסכים.

## הרצה

```bash
npm install
npm run dev
```

ואז לפתוח [http://localhost:3000](http://localhost:3000).

«כניסה עם נתוני דוגמה» פותחת את הטופס עם ארגון, איש קשר ומודולים בדויים. משם אפשר לעבור בין השלבים ולפתוח «צפייה בדמו חי».
